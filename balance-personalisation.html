Build notes
  • Since 241857 is an editor paywall, each variant can be a copy of it. Text and visibility are switched on user.onboarding_goal_1, user.age_onboarding and the other attributes, with control copy as the default branch. The alternative is a framework rebuild that reads the same attributes.
  • Variants based on goal and sleep answers need Balance to set those attributes before registering the onboarding placement. Goals are now set for ~64% of new installs (since 2026-11-04).
  • Content names (Wind Down, Back to Sleep, Flow State, Morning Brew, Foundations, Awake in the night) come from the App Store listing and reviews.
